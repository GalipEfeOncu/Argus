# Security policy

## Supported versions

Argus has not published a stable release. Security fixes currently target the
`main` branch and will be included in the next release candidate after its
pre-publish gates pass.

## Report a vulnerability

Use the repository's private vulnerability-reporting channel under **Security →
Advisories → Report a vulnerability**. If that channel is unavailable, contact
the repository owner privately. Do not include exploitable details, credentials,
or affected user data in a public issue.

Include the affected version or commit, platform, impact, minimal reproduction,
and any suggested mitigation. The maintainers will acknowledge the report,
validate its scope, coordinate a fix and release, and credit the reporter when
requested and safe. No response-time SLA is promised before the first stable
release.

The product security boundaries and disclosure-safe design are documented in
[docs/SECURITY.md](docs/SECURITY.md) and the
[threat model](docs/THREAT_MODEL.md).
